I build the payment layer autonomous agents actually need: wallets, spend policy, settlement, and receipts — not a checkout form bolted onto an LLM.

```mermaid
flowchart LR
  A[Agent] --> P[Spend policy]
  P --> S[Crypto / card / on-chain]
  S --> R[Sealed receipt]
```

## Work

| Project | What it is |
| --- | --- |
| [**AIPaySDK**](https://github.com/SumitShinde0702/aipaysdk) | Chain-agnostic SDK for agent identity, spend limits, and settlement. [aipaysdk.com](https://aipaysdk.com) |
| [**GateX**](https://github.com/SumitShinde0702/AgentixPlayground) | Agents that buy without being hijacked — policy, identity, and sealed receipts. [Live demo](https://main.db3ju8bxs5af1.amplifyapp.com/) |
